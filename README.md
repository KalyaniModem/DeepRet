# DeepRet - Deep Learning-Based Retinal Disease Detection

## Overview

DeepRet is a deep learning project developed to detect retinal diseases from fundus images using transfer learning. The project compares the performance of EfficientNetB3 and ResNet50 models on the ODIR-5K retinal image dataset.

---

## Dataset

- Dataset: ODIR-5K (Ocular Disease Intelligent Recognition)
- Medical retinal fundus images
- Multi-label retinal disease classification

---

## Models Used

- EfficientNetB3
- ResNet50

Both models were implemented using TensorFlow/Keras with transfer learning.

---

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

---

## Project Workflow

1. Data Preprocessing
2. Image Augmentation
3. Model Training
4. Model Evaluation
5. Disease Prediction

---

## Results

- Compared EfficientNetB3 and ResNet50 performance.
- EfficientNetB3 achieved better validation performance and was selected as the final model.
